# 相続のきほん（souzoku-kihon）

だれが相続人？何分の1ずつ？放棄はいつまで？家族の場面（配偶者・子・親・きょうだい・遺言など）を見て、民法の決まりどおりの答えを選ぶ1日5問の学習ゲーム。正解したら「これは、どの決まり？」も選ぶ。
